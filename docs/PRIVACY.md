# 数据与隐私

本应用没有登录系统、遥测或日志上传服务。

| 数据 | 用途与存放位置 |
| --- | --- |
| Power.log | 只读本地游戏日志，恢复实体与对局状态 |
| Decks.log | 开启收录后，尝试读取完整套牌代码 |
| cards.json | 下载并缓存的中文卡牌数据 |
| decks.json | 本机保存的套牌收藏与选择 |
| deck.json | 旧版数据，迁移后保留 |
| UserDefaults | 日志目录、浮窗位置、外观和收录偏好 |

点击「开启游戏日志」会修改用户目录的 `Library/Preferences/Blizzard/Hearthstone/log.config`，修改前备份已存在的配置。

网络请求包括：从 `api.hearthstonejson.com` 下载中文卡牌库、从 `art.hearthstonejson.com` 加载预览卡图。卡图请求包含卡牌 ID；服务提供者可以看到普通网络请求信息。套牌和日志不会作为请求内容发送。

「收藏自动收录」默认关闭。开启后，只在检测到剪贴板变化且炉石处于前台时读取文本，并尝试解析套牌代码。不保存其他复制内容。

本仓库的 `.gitignore` 排除游戏日志、用户套牌 JSON、下载卡牌数据、构建目录、应用和压缩包。自动测试使用合成日志。报告错误时，请去除战网昵称、标签、账号标识和个人文件路径；优先提供最小事件片段。
