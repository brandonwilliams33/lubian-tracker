# 使用指南

## 安装

需要 macOS 13 或更新版本。开发者安装 Xcode Command Line Tools 后，在仓库根目录运行 `zsh build.command`；生成的 `dist/炉边记牌器.app` 可拖入“应用程序”，压缩包可分享给其他 Mac 用户。

构建包含 Apple Silicon 和 Intel 两种架构。目前仅使用本地临时签名，未完成 Developer ID 签名和公证。macOS 可能阻止下载的应用运行；请只运行来源可核验的构建，不要关闭系统安全机制。

## 连接对局

1. 点击「开启游戏日志」，应用备份已有配置，再更新 Power、Decks 和 LoadingScreen 日志配置。
2. 完全退出并重新启动炉石，进入对局。
3. 默认安装会尝试发现 `/Applications/Hearthstone/Logs`；自定义安装请点「选择日志」并选择实际 Logs 文件夹。
4. 点击「更新中文卡牌库」，下载卡牌名称与效果。下载失败时保留已有缓存。
5. 点击「进入对局视图」，主窗口隐藏，菜单栏图标可重新打开设置。

「自动识别我方」通过起手牌揭示推断本地玩家；判断错误或旁观时可关闭并手选编号。玩家编号不表示先后手。

## 多套牌

「导入牌组」支持游戏复制出的完整文本、单独套牌代码以及 `2 CS2_029` 形式。可填写名称，也可从游戏导出标题取名。

每次导入都保存到收藏，不覆盖其他构筑。重复内容去重，同名新构筑创建版本。旧版单套牌文件会自动迁移。下拉列表可切换，旁边可以重命名。

开启「收藏自动收录」后，在炉石前台复制每副套牌一次，等待约两秒即可保存，不必切回记牌器。需要先加载中文卡牌库。修改构筑后再次复制收录。

**仅进入收藏不会保证收录所有套牌。** 完整收藏读取需要额外客户端信息；当前 Decks.log 路径只尝试识别明确的完整套牌代码，尚无本机真实样本验证。

开启「开局自动识别」后，起手与后续原始卡牌信息参与匹配：唯一候选自动选中；相似构筑等待更多抽牌；无候选则显示日志已知卡牌。手动切换会关闭自动识别，需再次开启才能恢复。

## 浮窗与预览

- 左右面板独立折叠；折叠后保留关键数量与下一次疲劳。
- 关闭「点击穿透」可滚动、悬停/点击预览、拖动和缩放。
- 开启「点击穿透」后鼠标直接操作游戏，列表不接收鼠标。
- 「恢复两侧位置」重新启用跟随布局，找回越界窗口。
- 卡图在线加载，失败时显示占位提示；已缓存的效果文字仍可显示。

## 牌库顶和疲劳

牌库顶目前支持探底的关联实体与揭示事件，未知时不会猜测。抽走、洗牌或开始新局会清除旧提示。其他卡牌的置顶机制尚未全面覆盖。

疲劳显示已记录次数与下一次伤害。中途连接且缺少开局事件、特殊伤害修正等情况需要结合游戏实际状态判断。

## 排查

| 现象 | 检查 |
| --- | --- |
| 等待 Power.log | 是否开启日志后完全重启炉石，并开始对局 |
| 显示上一副牌 | 开启自动识别；确认当前构筑已保存，尚未匹配时检查状态文字 |
| 无法滚动或预览 | 关闭点击穿透 |
| 复制后没收录 | 开启自动收录、保持炉石前台、确认已加载卡牌库；也可手动导入 |
| 牌库顶未知 | 当前没有受支持的明确揭示，或刚发生洗牌 |
| 卡图加载失败 | 检查网络，文字效果不依赖每次联网 |

本地数据在 `~/Library/Application Support/LubianTracker/`。反馈问题时请勿上传整个目录或未经脱敏的日志。
